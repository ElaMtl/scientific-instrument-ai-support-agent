# Draft

- Non-Functional Requirements

\*\* NFR-1 — Accuracy

Ответы не должны hallucinate technical specs.
The system shall validate attachment matching accuracy before including files in generated drafts.

\*\* NFR-2 — Security

Email access должен быть secure.

\*\* NFR-3 — Human approval

AI response требует validation before sending.

\*\* NFR-4 — Response speed

Draft generation ≤ 30–60 sec.

\*\* NFR-5 — Maintainability

Owner должен иметь возможность:

- добавлять templates,
- корректировать ответы,
- обновлять knowledge base.
